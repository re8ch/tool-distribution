Install

Install plugins from one Git source.

Claude, Claude Code and Codex read the same repository. It ships both marketplace manifests with the same five plugin names.

  1. Add re8ch/tool-distribution as a marketplace.
  2. Install a plugin from re8ch-tools.
  3. Sign in through OAuth when the client first calls a tool.

Installing the files does not grant permission to operate RE8CH services. WorkBuddy connector bundles are in distribution/workbuddy.

Claude Code
claude plugin marketplace add re8ch/tool-distribution
claude plugin install re8ch-tenant@re8ch-tools

Policy

Known external gates

Vendor review and registration

OpenAI, Anthropic public directories, Cursor public Marketplace and WorkBuddy market publication require vendor review. Cursor additionally requires a public open-source source repository. WorkBuddy and Coze need platform OAuth callback/client registration because the current Dex issuer has no dynamic client-registration endpoint.

Closed channel

New publication from Coze to Doubao is unavailable: Coze removed that channel on 2026-07-01. Existing Doubao publications are unaffected.

The catalog is validated on every pull request before it is published here.
